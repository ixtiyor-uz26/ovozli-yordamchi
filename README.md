# Ovozli yordamchi

O'zbekcha ovozli buyruqlar bilan telefonni boshqarish:

- «Onamga telefon qil», «Dadamga qo'ng'iroq qil» — yaqinlar ro'yxati yoki kontaktlardan topib qo'ng'iroq qiladi
- «YouTube'dan Shoxrux qo'shig'ini qo'y», «Musiqa qo'y» — YouTube'da qidiradi
- «Telegramga kir», «Instagramni och», «Sozlamalarni och» — ilovani ochadi

## APK ni yuklab olish
Kod yangilanganda GitHub o'zi APK yig'adi. Tayyor faylni **Releases** bo'limidan `OvozliYordamchi.apk` nomi bilan yuklab olasiz.
